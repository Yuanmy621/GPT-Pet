# 现有 Pets 插件内的优化范围

用户已确认仅使用现有 Pets 插件。本项目继续以原有宠物身份更新，不创建独立桌宠程序或新的宠物身份。

| 原优化顺序 | 本轮处理方式 |
| --- | --- |
| 小尺寸专用形象 | 统一重绘基础形象、九组动作及十六方向，增强脸部、眼睛和轮廓的可辨认性。 |
| 自然动作节奏 | 收敛动作幅度、减少身体模板变化，改进循环和状态切换；随机调度、额外过渡帧及时长配置无法通过当前素材接口设置。 |
| 明确任务反馈 | 让托腮工作、双掌等待、侧视检查等现有状态更容易区别；不编造任务进度。点击任务入口不在当前接口能力内。 |
| 专注模式、任务入口、互动触发、位置与尺寸偏好、陪伴提醒 | 需要客户端行为接口；本轮不将预览页的控制项冒充为 Pets 已新增的功能。 |

后续若插件开放相关接口，再按原优先级评估实现。
