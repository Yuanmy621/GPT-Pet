# 待机与工作动画修订

针对待机、工作播放时的跳变和细节不清，重绘这两组源动画，并更新原有宠物。

- 待机：固定身体、衣裙与翼的姿态，连续眨眼后回到睁眼状态。
- 工作：手始终贴近下巴，通过眼睑变化表达专注，减少手势来回切换。
- 清晰度：增强眼睛和紫灰轮廓对比，保留银白、淡紫配色与原角色身份。
- 其余动作和方向：沿用现有已批准的姿势，经内置合成工具统一登记与一次边缘清理。

## 验证结果

最终 PNG 为 1536×2288、73 个有效帧、15 个透明空白格。内置结构、边缘、质量门禁和 Pets 文件预检通过。三位独立方向盲检评审按多数票确认全部要求的轴向。跳跃峰值离地 27 像素，落地偏差为 0。

方向连续性报告保留 157.5°→180° 的局部像素差异提示；正常尺寸复核确认没有方向倒退、基线跳动或身份变化。

| 同底色原生帧的指标 | 待机 | 工作 |
| --- | ---: | ---: |
| 循环首尾 RGB 平均差异（原版） | 7.054 | 6.995 |
| 循环首尾 RGB 平均差异（新版） | 2.897 | 3.202 |
| 首尾差异减少 | 58.9% | 54.2% |
| 衣裙区域平均帧间差异减少 | 44.3% | 42.6% |

这些数值来自相同浅灰底色上的解码像素对比，用于检查画面跳变；它们不能证明应用的实际帧率。每帧仍遵守 Pets 的 192×208 固定尺寸，客户端播放调度与缩放不由这个资产项目控制。

来源、布局引导和源动画在 `run/references/`、`run/prompts/`、`run/decoded/`；所有实际验证报告与检查图在 `run/qa/`。预览均来自最终编码的精灵图。云端 Library 接口不可用，工作资产保存在本地此目录。
